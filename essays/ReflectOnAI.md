## Introduction 

Artificial Intelligence is really transforming education by providing innovative tools that enhance learning experience and really tailor educational content to fit a person’s needs. AI’s role is to optimize development processes, and provide a quick learning resource for students and professionals. AI is especially impactful in software engineering because it has the ability to generate code based on prompts. Throughout my ICS 314 class, the two AI that I have used the most are ChatGPT and Claude AI. ChatGPT is really good because it's free so I can ask unlimited questions without worrying about cool downs. On the other hand, Claude AI is also free with the free plan but there is a limited amount of prompts until there is a cooldown which I have to wait for a while before I can ask questions again. Towards the end of the class, we are tasked with building a website. Claude AI is really good here because it’s tailor towards web development.  

## Personal Experience with AI

Experience WODs 
For the Functional Programming Experience WOD, I didn’t know how to start with the code but then I copy and pasted the problem into ChatGPT and it gave me a detailed explanation of the problem and the answer which allowed me to fully understand the problem and why the answer worked. 

In-class Practice WODs 
For the Murphy’s Practice WOD, I spent so much time trying to style the website but then I asked ChatGPT to center my image and it changed the code for me and centered the image for me just like how i would’ve liked it.

In-class WODs 
For the NextJS Aloha Beer in-class WOD, Since i already have done the same website in React, I copy my code in React into ChatGPT and asked to change to NextJS, it promptly switched the coding for me to NextJS. 

Essays 
For the Reflect on UI Essay, I didn’t really know how to start the essay and I asked ChatGPT to give me idea about reflection on Bootstrap 5.

Final project 
For the final project, I used Claude AI to generate code for the frontend of the website. 

Learning a concept / tutorial 
A concept that I learned with ChatGPT is the fundamentals of html and css along with Javascript. ChatGPT explained to me how 3 of them work together to make a functional website. 

Answering a question in class or in Discord 
I used ChatGPT to answer questions during the extra credit Jeopardy activity in class, this was a fun activity and ChatGPT helped me with coming up answer fast.

Asking or answering a smart-question 
Asking smart questions really allowed me to fully utilize ChatGPT because asking good specific questions is crucial to get the right answers that I wanted.

Coding example e.g. “give an example of using Underscore .pluck” 
I used ChatGPT to give me an example of how a react template would look like.

Explaining code 
I really had a hard time with the database part of the class and I used ChatGPT to explain how the code in the tutorial works.

Writing code 
I mostly ChatGPt and Claude AI to write code especially for the class assignments and front end of the project

Documenting code
Going back to explaining code, when i asked ChatGPT to explain code for me, it also generated comments in the code which allowed me to understand how each line of code works.

Quality assurance e.g. “What’s wrong with this code <code here>” or “Fix the ESLint errors in <code here>” 
I have so many ESLint errors in my code and I copy my code and the error in ChatGPT and it was able to help me fix the errors most of the time.

Other uses in ICS 314 not listed
I also used ChatGPT to help me understand concepts in Javascript that I had a really hard time understanding like callback functions.



## Impact on Learning and Understanding

AI has definitely been an outstanding learning tool that enhanced my learning experience. It’s both good and bad. It’s really good for the theory part of the class because it is really good at explaining concepts in a way that is easy to understand. But on the other hand I think my over reliance on AI has definitely hurt me more than it helped. AI is really good at doing tedious/repetitive tasks. But it’s so good at problem solving that if I pasted in a prompt it answers it for me instantly. This really hurts my problem solving skills because I'm not struggling to understand or fix the issue anymore since ChatGPT does it for me so I did not learn the concepts in this class as deeply as I would like to. In my opinion ChatGPT is not good for practical learning, because we need to struggle to find the answer to actually understand why things work the way they work.
